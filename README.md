 Driver Drowsiness Detection 🚗💤:

📌 Overview:
This project implements a **real-time driver drowsiness detection system** using computer vision and deep learning.  
A custom-trained **Keras model** (via Teachable Machine) classifies facial states into *Awake* or *Drowsy*, while **cvzone’s FaceDetectionModule** ensures robust face tracking.  
When drowsiness is detected, the system triggers an **auditory alert (beep)**, simulating an in-car safety mechanism.

---

🛠 Tech Stack:
- Python  
- OpenCV  
- cvzone (FaceDetection + Classification)  
- TensorFlow / Keras (Teachable Machine model)  

---

⚙️ Features:
- Real-time face detection  
- Classification into **Awake** or **Drowsy**  
- Beep alert when drowsy  
- Organized dataset folders for training and testing
